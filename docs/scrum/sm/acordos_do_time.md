# Acordos do time (Working Agreements) — Sprint Única

## Comunicação

- Canal assíncrono: grupo WhatsApp do time.
- Daily de 15 min.
- Bloqueio crítico: resposta em até 4h úteis.

## Fluxo de trabalho

- Todo trabalho passa no Projects.
- WIP máximo: 2 cards por pessoa em andamento.
- Padrão por task: documentação inicial -> testes (TDD) -> pseudocódigo -> documentação final.
- Card só vai para Done com [DoD](../definition_of_done.md) completa.

## Qualidade

1. Red -> Green -> Refactor em pseudocódigo.
2. Todo teste deve apontar para pseudocódigo correspondente.
3. Toda PR deve mencionar task e rastreabilidade.
