## Modelo de fluxo

| Coluna | Quando usar |
|--------|-------------|
| Backlog | Item ainda não refinado |
| Ready | Item pronto para execução |
| In Progress | Item em desenvolvimento |
| Review | Aguardando revisão |
| Testing | Em validação TDD/CI |
| Done | DoD cumprida |

## Campos recomendados

| Campo | Uso |
|-------|-----|
| Sprint | Sprint Unica |
| Story ID | Ex.: `T-S2-E4-02` |
| Story Points | Estimativa |
