# Teste pseudocodigo: cadastro de usuario

Task: T-S1-E4-01
Historia: E4-US01
Fonte: docs/scrum/sprint_backlog/sprint_backlog_ze_mercearia.md

Cenario: cadastrar usuario gerente com dados validos
Dado que nao existe usuario com login "gerente_loja_01"
Quando o administrador informar nome, login, senha e papel GERENTE
Entao o sistema deve criar um Usuario com status ATIVO
E deve gerar um id unico
E deve salvar senha como senha_hash
E deve persistir o usuario no repositorio simulado

Cenario: rejeitar cadastro sem login
Dado que o administrador abriu o cadastro de usuario
Quando o login estiver vazio
Entao o sistema deve retornar erro "login e obrigatorio"
E nenhum usuario deve ser persistido

Cenario: rejeitar cadastro sem senha
Dado que o administrador abriu o cadastro de usuario
Quando a senha estiver vazia
Entao o sistema deve retornar erro "senha e obrigatoria"
E nenhum usuario deve ser persistido

Cenario: rejeitar login duplicado
Dado que ja existe usuario com login "gerente_loja_01"
Quando o administrador tentar cadastrar outro usuario com o mesmo login
Entao o sistema deve retornar erro "login ja cadastrado"
E deve manter apenas o usuario original no repositorio

Cenario: rejeitar papel invalido
Dado que os papeis permitidos sao ADMIN e GERENTE
Quando o administrador informar papel "CLIENTE"
Entao o sistema deve retornar erro "papel invalido"
E nenhum usuario deve ser persistido

---

Pseudo teste executavel:

Funcao executar_teste_cadastro_usuario():
  1. cenario_cadastrar_gerente_valido()
  2. cenario_rejeitar_sem_login()
  3. cenario_rejeitar_sem_senha()
  4. cenario_rejeitar_login_duplicado()
  5. cenario_rejeitar_papel_invalido()
  6. retornar "todos os cenarios executados"

Funcao cenario_cadastrar_gerente_valido():
  dado repositorio_usuarios = lista vazia
  dado dados = {
    nome: "Gerente Loja 1",
    login: "gerente_loja_01",
    senha: "senha_demo",
    papel: "GERENTE"
  }
  quando resultado = cadastrar_usuario(dados)
  entao assert resultado.status == "sucesso"
  entao assert resultado.usuario.id == "USU-001"
  entao assert resultado.usuario.status == "ATIVO"
  entao assert resultado.usuario.senha_hash == "hash_senha_demo"
  entao assert quantidade(repositorio_usuarios) == 1

Funcao cenario_rejeitar_sem_login():
  dado repositorio_usuarios = lista vazia
  dado dados = { nome: "Gerente Loja 1", login: "", senha: "senha_demo", papel: "GERENTE" }
  quando resultado = cadastrar_usuario(dados)
  entao assert resultado.erro == "login e obrigatorio"
  entao assert quantidade(repositorio_usuarios) == 0

Funcao cenario_rejeitar_sem_senha():
  dado repositorio_usuarios = lista vazia
  dado dados = { nome: "Gerente Loja 1", login: "gerente_loja_01", senha: "", papel: "GERENTE" }
  quando resultado = cadastrar_usuario(dados)
  entao assert resultado.erro == "senha e obrigatoria"
  entao assert quantidade(repositorio_usuarios) == 0

Funcao cenario_rejeitar_login_duplicado():
  dado repositorio_usuarios contem usuario com login "gerente_loja_01"
  dado dados = { nome: "Outro Gerente", login: "gerente_loja_01", senha: "senha_demo", papel: "GERENTE" }
  quando resultado = cadastrar_usuario(dados)
  entao assert resultado.erro == "login ja cadastrado"
  entao assert quantidade(repositorio_usuarios) == 1

Funcao cenario_rejeitar_papel_invalido():
  dado repositorio_usuarios = lista vazia
  dado dados = { nome: "Cliente Teste", login: "cliente_01", senha: "senha_demo", papel: "CLIENTE" }
  quando resultado = cadastrar_usuario(dados)
  entao assert resultado.erro == "papel invalido"
  entao assert quantidade(repositorio_usuarios) == 0
