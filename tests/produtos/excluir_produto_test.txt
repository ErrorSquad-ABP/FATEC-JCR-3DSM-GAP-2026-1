# Teste pseudocodigo: exclusao logica de produto

Task: T-S2-E1-01
Historia: E1-US03
Fonte: docs/scrum/sprint_backlog/sprint_backlog_ze_mercearia.md

Cenario: excluir um produto com sucesso (exclusao logica)
  Dado que o produto "PROD-001" existe com status "ATIVO"
  Quando o gerente solicitar a exclusao do produto "PROD-001"
  Entao o sistema deve alterar o status do produto para "INATIVO"
  E o sistema deve confirmar "produto excluido com sucesso"

Cenario: tentar excluir um produto inexistente
  Dado que o produto "PROD-999" nao existe no sistema
  Quando o gerente solicitar a exclusao do produto "PROD-999"
  Entao o sistema deve retornar erro "produto nao encontrado"

Cenario: garantir que produto inativo permanece no repositorio
  Dado que o produto "PROD-001" foi excluido logicamente
  Quando o administrador buscar todos os produtos
  Entao o produto "PROD-001" ainda deve constar na lista
  Mas seu status deve ser "INATIVO"

---

Pseudo teste executavel:

Funcao executar_testes_exclusao_produto():
  1. cenario_excluir_sucesso()
  2. cenario_excluir_inexistente()
  3. cenario_validar_exclusao_logica()
  4. retornar "sucesso"

Funcao cenario_excluir_sucesso():
  dado produto = { id: "PROD-001", status: "ATIVO" }
  quando resultado = excluir_produto(produto.id)
  entao assert resultado.sucesso == verdadeiro
  entao assert buscar_produto(produto.id).status == "INATIVO"

Funcao cenario_excluir_inexistente():
  dado produto_id = "PROD-999"
  quando resultado = excluir_produto(produto_id)
  entao assert resultado.sucesso == falso
  entao assert resultado.erro == "produto nao encontrado"

Funcao cenario_validar_exclusao_logica():
  dado produto_id = "PROD-001"
  quando excluir_produto(produto_id)
  quando todos = buscar_todos_produtos_incluindo_inativos()
  entao assert todos.contem(produto_id) == verdadeiro
  entao assert buscar_produto(produto_id).status == "INATIVO"
