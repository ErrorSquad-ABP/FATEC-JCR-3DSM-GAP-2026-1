# Teste pseudocodigo: estrutura e convencoes do repositorio

Task: T-S1-INF-01
Fonte: docs/scrum/sprint_backlog/sprint_backlog_ze_mercearia.md

Cenario: repositorio possui estrutura base da Sprint 1
Dado que o time iniciou a Sprint 1
Quando a estrutura do repositorio for verificada
Entao devem existir as pastas rastreaveis:
- src/
- tests/
- docs/
- docs/scrum/

Cenario: pseudocodigo possui convencao documentada
Dado que novos modulos serao criados em pseudocodigo
Quando um dev consultar a documentacao de src/
Entao deve encontrar a convencao para:
- arquivos .txt ou .md
- nomes de pastas em minusculo
- nomes de arquivos em snake_case
- separacao por responsabilidade/modulo

Cenario: testes acompanham os modulos de pseudocodigo
Dado que uma funcionalidade for adicionada em src/<modulo>/
Quando seus testes forem adicionados
Entao eles devem ficar em tests/<modulo>/
E devem descrever cenario, entrada, passos e resultado esperado

---

Pseudo teste executavel:

Funcao executar_teste_estrutura_convencoes_repo():
  1. cenario_estrutura_base_sprint_1()
  2. cenario_convencao_pseudocodigo_documentada()
  3. cenario_testes_acompanham_modulos()
  4. retornar "todos os cenarios executados"

Funcao cenario_estrutura_base_sprint_1():
  dado pastas_obrigatorias = ["src", "tests", "docs", "docs/scrum"]
  para cada pasta em pastas_obrigatorias:
    quando existe = verificar_pasta(pasta)
    entao assert existe == verdadeiro

Funcao cenario_convencao_pseudocodigo_documentada():
  dado documento = ler_arquivo("src/README.md")
  entao assert documento contem "arquivos `.txt` ou `.md`"
  entao assert documento contem "pastas por modulo"
  entao assert documento contem "snake_case"
  entao assert documento contem "Separar responsabilidades"

Funcao cenario_testes_acompanham_modulos():
  dado modulo = "auth"
  quando caminho_src = "src/" + modulo
  quando caminho_tests = "tests/" + modulo
  entao assert verificar_pasta(caminho_src) == verdadeiro
  entao assert verificar_pasta(caminho_tests) == verdadeiro
  entao assert padrao_teste_contem_cenario_entrada_passos_resultado() == verdadeiro
