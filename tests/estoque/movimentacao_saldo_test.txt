# Teste pseudocodigo: incremento e decremento de saldo

Task: T-S2-E2-03
Historia: E2-US03, E2-US04
Fonte: docs/scrum/sprint_backlog/sprint_backlog_ze_mercearia.md

Cenario: incremento de saldo com sucesso
  Dado que o estoque atual de um produto e 10
  Quando o sistema solicitar incremento de 5
  Entao o novo saldo deve ser 15

Cenario: decremento de saldo com sucesso
  Dado que o estoque atual de um produto e 20
  Quando o sistema solicitar decremento de 8
  Entao o novo saldo deve ser 12

Cenario: erro ao incrementar quantidade negativa
  Dado que o sistema recebeu uma solicitacao de incremento
  Quando a quantidade informada for -5
  Entao o sistema deve retornar erro "quantidade invalida para incremento"

Cenario: erro ao decrementar alem do saldo disponivel
  Dado que o estoque atual e 5
  Quando o sistema solicitar decremento de 6
  Entao o sistema deve retornar erro "saldo insuficiente para decremento"
  E o saldo deve permanecer 5

Cenario: erro ao decrementar quantidade negativa ou zero
  Dado que o sistema recebeu uma solicitacao de decremento
  Quando a quantidade informada for 0
  Entao o sistema deve retornar erro "quantidade invalida para decremento"

---

Pseudo teste executavel:

Funcao executar_testes_movimentacao_saldo():
  1. cenario_incremento_sucesso()
  2. cenario_decremento_sucesso()
  3. cenario_incremento_negativo()
  4. cenario_decremento_insuficiente()
  5. cenario_decremento_zero()
  6. retornar "sucesso"

Funcao cenario_incremento_sucesso():
  dado saldo = 10
  quando novo_saldo = calcular_incremento(saldo, 5)
  entao assert novo_saldo == 15

Funcao cenario_decremento_sucesso():
  dado saldo = 20
  quando novo_saldo = calcular_decremento(saldo, 8)
  entao assert novo_saldo == 12

Funcao cenario_incremento_negativo():
  dado saldo = 10
  quando resultado = calcular_incremento(saldo, -5)
  entao assert resultado.erro == "quantidade invalida para incremento"

Funcao cenario_decremento_insuficiente():
  dado saldo = 5
  quando resultado = calcular_decremento(saldo, 6)
  entao assert resultado.erro == "saldo insuficiente para decremento"

Funcao cenario_decremento_zero():
  dado saldo = 10
  quando resultado = calcular_decremento(saldo, 0)
  entao assert resultado.erro == "quantidade invalida para decremento"
