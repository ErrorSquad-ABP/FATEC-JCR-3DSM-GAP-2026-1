# Teste pseudocodigo: registro de saida manual de estoque

Task: T-S2-E2-02
Historia: E2-US04
Fonte: docs/scrum/sprint_backlog/sprint_backlog_ze_mercearia.md

Cenario: registrar saida de produto com sucesso
  Dado que o produto "PROD-001" tem saldo 10 na "LOJA-01"
  Quando o gerente registrar saida manual de 4 unidades
  Entao o saldo do produto na "LOJA-01" deve passar para 6
  E deve ser criado um log de movimentacao do tipo "SAIDA"
  E o log deve conter o motivo (venda/perda/vencimento)

Cenario: rejeitar saida com saldo insuficiente
  Dado que o produto "PROD-001" tem saldo 3 na "LOJA-01"
  Quando o gerente tentar registrar saida de 5 unidades
  Entao o sistema deve retornar erro "saldo insuficiente"
  E o saldo deve permanecer 3

Cenario: rejeitar saida com quantidade zero ou negativa
  Dado que o gerente abriu a tela de saida de estoque
  Quando informar a quantidade -1
  Entao o sistema deve retornar erro "quantidade deve ser maior que zero"

Cenario: rejeitar saida para produto ou loja inexistente
  Dado que o sistema esta operacional
  Quando o gerente informar dados de uma loja nao cadastrada
  Entao o sistema deve retornar erro "loja nao encontrada"

---

Pseudo teste executavel:

Funcao executar_testes_registro_saida():
  1. cenario_saida_sucesso()
  2. cenario_saida_saldo_insuficiente()
  3. cenario_saida_quantidade_invalida()
  4. cenario_saida_loja_inexistente()
  5. retornar "sucesso"

Funcao cenario_saida_sucesso():
  dado produto = "PROD-001"
  dado loja = "LOJA-01"
  dado saldo_inicial = 10
  quando resultado = registrar_saida(produto, loja, 4, "VENDA")
  entao assert resultado.sucesso == verdadeiro
  entao assert buscar_saldo(produto, loja) == 6
  entao assert buscar_ultimo_log().tipo == "SAIDA"
  entao assert buscar_ultimo_log().motivo == "VENDA"

Funcao cenario_saida_saldo_insuficiente():
  dado produto = "PROD-001"
  dado loja = "LOJA-01"
  dado saldo_inicial = 3
  quando resultado = registrar_saida(produto, loja, 5, "VENDA")
  entao assert resultado.sucesso == falso
  entao assert resultado.erro == "saldo insuficiente"
  entao assert buscar_saldo(produto, loja) == 3

Funcao cenario_saida_quantidade_invalida():
  dado produto = "PROD-001"
  dado loja = "LOJA-01"
  quando resultado = registrar_saida(produto, loja, -1, "PERDA")
  entao assert resultado.sucesso == falso
  entao assert resultado.erro == "quantidade deve ser maior que zero"

Funcao cenario_saida_loja_inexistente():
  dado produto = "PROD-001"
  dado loja = "LOJA-INEXISTENTE"
  quando resultado = registrar_saida(produto, loja, 1, "VENDA")
  entao assert resultado.sucesso == falso
  entao assert resultado.erro == "loja nao encontrada"
